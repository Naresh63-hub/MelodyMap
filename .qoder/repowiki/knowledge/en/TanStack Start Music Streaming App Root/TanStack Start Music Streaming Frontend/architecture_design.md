The `src/` root is the TanStack Start application boundary: `router.tsx` composes the React Query provider and route tree, `__root.tsx` mounts the app shell, and `server.ts`/`start.ts` expose the Node entry that proxies YouTube audio streams. Cross-cutting concerns live in `lib/` (auth, error capture, offline storage, media-session hooks) and are consumed by both `routes/` and `components/music/ui`. Supabase integration is centralized under `integrations/supabase/` and attached via request/function middleware registered in the router so every route and function inherits auth context. The `components/music/*` UI layer depends on shared hooks (`use-audio-player`, `use-media-session`, `useSleepTimer`) and server helpers (`music.server.ts`, `deezer.server.ts`, `radio.server.ts`) to fetch and stream content, while `components/ui` provides primitive shadcn-style primitives reused across music panels.
