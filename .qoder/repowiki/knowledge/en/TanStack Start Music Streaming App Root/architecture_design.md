The root package orchestrates two child concerns: the `frontend_app` (a TanStack Start SPA/SSR app built by Vite/Nitro) and the `supabase_schema` (PostgreSQL migrations, RLS policies, triggers). The frontend consumes Supabase through `@supabase/supabase-js`, whose connection is driven by `VITE_*` env variables injected at build time by the Lovable TanStack Vite config; the server entry is redirected to `server.ts` so SSR routes can proxy audio and enforce auth. Shared tooling lives here: TypeScript strict mode with `@/*` path alias, ESLint + Prettier rules, Tailwind v4 via `@tailwindcss/vite`, Radix UI primitives, and Zod for runtime validation — all consumed uniformly by both the frontend code and any Supabase helper modules. Build targets Cloudflare via Nitro's default target, while dev uses Bun (`bunfig.toml` enforces a 24h minimum release age on installs as a supply-chain guard).
