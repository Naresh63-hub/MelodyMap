# Security Policy

## Supported Versions

The following versions of **MelodyMap** currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The MelodyMap team takes the security of our application and users seriously.

If you believe you have discovered a security vulnerability in MelodyMap:

1. **Do not disclose the issue publicly.** Please do not open a public GitHub issue.
2. Report the vulnerability privately via **[GitHub Private Vulnerability Reporting](https://github.com/Naresh63-hub/Musicplayer/security/advisories/new)** or by emailing the project maintainer at `nareshg6305@gmail.com`.
3. Include detailed steps to reproduce the issue, proof of concept (if applicable), and affected environment/browser/device details.

### Response Timeline

- **Initial Response**: Within 48 hours acknowledging receipt of the report.
- **Triage & Status Update**: Within 5 business days detailing evaluation and planned timeline.
- **Resolution**: A security fix will be released and credit will be acknowledged in the security advisory.
